# vishnur.dev

My personal site. Plain HTML, CSS, and JavaScript, no build step.

- `index.html` is the page, with each tab as a section
- `app.js` holds tabs, weather, jobs, projects, books, and movies
- `puzzle.js` runs the puzzle game; drawings live in `photos/`

To run it locally: `python3 -m http.server` in this folder, then open http://localhost:8000.
